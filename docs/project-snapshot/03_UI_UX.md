# UI / UX

## Экраны

- Main Menu: `Assets/MainMenu.unity`, `MainMenuController`.
- Gameplay: `Assets/Scenes/Main.unity`, `GameManager`, `UIManager`, `SolitaireSceneRefs`.
- Level Selection popup: `LevelSelectionPopup`.
- Settings popup: `SettingsPopup`.
- Daily Rewards popup: `DailyRewardsPopup`.
- Chest Chase popup: `ChestChasePopup`.
- Collection Book popup: `CollectionBookPopup`.
- Shop popup: `ShopPopup`.
- Pause popup: `PauseMenuPopupController` / authored `PauseSettingsPopup`.
- Restart confirmation popup: `RestartConfirmationPopupController`.
- Level failed popup: runtime-generated by `UIManager`.
- Lives empty popup: runtime-generated by `UIManager`.
- Win screen: `WinScreenView`.
- Runtime dev tools: `RuntimeDevTools`, likely development-only UI but bootstrap attributes require release check.

## Popup/modal окна

- Authored or located: `PauseSettingsPopup`, `RestartConfirmationPopup`.
- Runtime-created by `UIManager`: `LevelFailedPopup`, `LivesEmptyPopup`.
- Main menu popups may exist in scene or be instantiated from `Resources/UI/MainMenu/LevelSelectionPopup.prefab`.

## Навигация между экранами

- `MainMenuController.OnPlayClicked`: selects last level, ensures seed, loads `Game`, `Main`, or `Assets/Scenes/Main.unity`.
- `SceneLoader.LoadGame`: similar scene fallback.
- `GameManager.ReturnToMainMenu`: loads `MainMenu` or `Assets/MainMenu.unity`.
- `LevelSelectionPopup.Show`: callback invokes play for selected level.
- Pause popup can restart or return to main menu.
- Win flow auto-advances to next level after delay/ad and restarts gameplay scene state.

## Связь UI с gameplay

- `GameManager` calls `uiManager.Initialize`, `UpdateMoves`, `UpdateDeckCounter`, `UpdateCoins`, `UpdateHintCount`, `UpdateUndoCount`, `ShowStatus`, popup methods.
- `UIManager` wires buttons to `GameManager` actions.
- `SolitaireSceneRefs` also updates moves text directly.
- `CardView`, `CardColumn`, `GoalSlot`, `DrawSlot` are UI components and gameplay containers at the same time.

## Мобильная адаптация

Факты:

- CanvasScaler set to `ScaleWithScreenSize`, reference `1920x1080`, match 0.5 in `SolitaireSceneRefs.EnsureCanvasSetup`.
- `SafeAreaRoot` exists by name and is stretched to fill parent.
- Layout supports 3, 4, 5 columns.
- `UIManager.ResolveBottomButtonSize` sizes bottom buttons from available width.

Требует проверки:

- `Screen.safeArea` usage not found.
- Portrait/landscape support unknown.
- Android/iOS not verified.
- Small phone resolutions may break fixed insets such as `HudTopInset`, `MovesTopInset`, `RightDeckInset`.

## Canvas / RectTransform / Layout Groups

- Gameplay board uses `HorizontalLayoutGroup` on `ColumnSlotsRoot`.
- Columns and slots use `LayoutElement`.
- Many UI elements are positioned by direct `RectTransform` anchors/size/anchoredPosition.
- Runtime-created modals use full-screen overlay under `safeAreaRoot`.
- `CardColumn.RefreshLayout`, `GoalSlot.RefreshLayout`, `DrawSlot.RefreshLayout` manually position cards.

## Потенциальные проблемы разных разрешений

- Fixed pixel constants dominate gameplay HUD and board positioning.
- `GoalSlot`/`CardColumn` card size normalized to `170x248` in `GameManager.NormalizeGameplayProfile`, ignoring serialized layout profiles.
- `SolitaireSceneRefs` has reference layout constants for 196x286, while `GameManager` normalizes to 170x248 for active gameplay.
- `DeckArea` alignment computes y from goal row, but fixed right inset remains.
- Popups use large absolute window sizes, e.g. DailyRewards `1700x1060`.

## Safe area risks

- `SafeAreaRoot` is a transform name, not confirmed safe-area implementation.
- Notch/home-indicator insets are not visibly applied.
- Top HUD and bottom HUD use fixed offsets from root edges.

## UI performance risks

- `UIManager.ApplyGameplayPolish` creates, destroys and restyles many elements.
- Popup classes call `GetComponentsInChildren` and create runtime hierarchy.
- `ForceMeshUpdate` is used in gameplay UI updates.
- Confetti/sparkles/floating text create/destroy GameObjects.
- Runtime textures/sprites are generated for rounded panels, vignettes and icons.
